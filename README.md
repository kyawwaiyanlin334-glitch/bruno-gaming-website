# Bruno Gaming — eFootball 2027 Coin Shop

Official coin top-up website for **Bruno Gaming**.

## Structure

```
bruno-gaming-website/
├── index.html          # Main page
├── css/
│   └── styles.css      # Styles
├── js/
│   └── app.js          # Shop, chat, admin, Firebase
└── README.md
```

## GitHub Pages

1. Create repo `bruno-gaming-website` (or any name)
2. Upload these files to the root (or `docs/`)
3. Settings → Pages → Deploy from branch `main` / root
4. Site URL: `https://YOUR_USER.github.io/bruno-gaming-website/`

## Custom domain (brunogaming.online)

1. Pages → Custom domain → `brunogaming.online`
2. DNS: CNAME → `YOUR_USER.github.io`

## Notes

- Firebase, LinkBus AI keys are in `js/app.js` — keep private if needed
- Logo: place `logo.png` next to `index.html` if you have one
- Single-page shop: order form, AI chat, admin panel
